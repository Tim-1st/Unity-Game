## À propos

Un jeu de plateforme développé avec Unity. Le joueur progresse en traversant et en terminant différents biomes.

## Comment jouer

- **Déplacements** : ZQSD
- **Saut** : Espace
- **But** : progresser à travers les niveaux en terminant les différents biomes les uns après les autres.
